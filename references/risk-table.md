# 实测频率安全参数表

> 全部来自真实长期运行迭代的实测（含踩坑记录）。**任何自动化逻辑不得越过红线列**。
> 不同账号/设备/内容领域阈值有差异，请以「先低后高、宁保守勿激进」自测校准。

## 核心红线（硬编码级）

| 操作 | 安全值 | 红线 | 说明 |
|---|---|---|---|
| 高频关键词搜索 | 废弃 | **单日密集搜索曾触发账号级安全验证** | 改用推荐流为主，搜索仅作低频兜底 |
| 搜索兜底间隔 | ≥4h | <4h | 兜底每次只搜 1 个词 |
| 评论发布（执行层） | 人工审核后低频 | 禁止自动批量 | 语义层只出草稿，发布是显式动作 |
| 单轮滚动采集 | ~80 卡片上限 | 无限滚动不设限 | 防拉取过量 |
| 滚动间隔 | 1.2-2.2s 随机 | <1s | 连续快速请求高风险 |
| 投喂轮次 | ≤2 次/天 | 超过 | 投喂是长期养号，不是冲量 |
| 投喂停留 | 10-20s/篇 | — | 真人阅读节奏 |
| 投喂点赞 | ≤2/轮 | 密集点赞 | 密集点赞易被识别为营销行为 |
| 风控冷却 | 触发即停 24h | 冷却期内任何操作 | 页面标题含 安全验证/请求太频繁 即冷却 |

## 时段纪律

| 时段 | 结论 | 依据 |
|---|---|---|
| 平台高峰（如 9-12 / 14-18） | 禁止自动化写操作 | 实测高峰时段操作失败率显著高于闲时 |
| 闲时 | 可跑 | 凌晨与工作时段失败率最低 |

## 处罚认知（平台规则）

平台处罚通常是分级递进：轻度=功能受限 → 中度=大部分功能受限 → 重度=封禁；一定周期内累计多次轻/中度可能触发更重处理。

**被限制处置（推荐流程）**：停跑 → 冷却数小时-数天 → 低频只读单测 → 恢复。禁止在受限期间反复试探（会加重处罚判定）。

## 观测与自愈

| 信号 | 判定 | 动作 |
|---|---|---|
| 页面标题出现 安全验证/验证码/请求太频繁 | 触发风控 | 写冷却时间戳 ≥24h，期间所有轮次跳过 |
| 采集 0 卡片 + 页面诊断异常 | 可能选择器失效/页面改版 | 输出诊断日志，人工检查（不自动改） |
| 卡片抽取正常但语义层全拒 | 候选质量问题 | 检查筛选题词与内容等级门槛 |
| pending 超 3h 未处理 | Agent 崩溃 | 归档 skipped 防死锁，下轮继续 |

## 校准建议

1. 新账号/新配置先跑 1-2 周低频，观察失败率与是否有验证页
2. 稳定无风控后再逐步上调到目标频率（每次只调一个参数）
3. 任何一次触发冷却，回退一档并保持至少一周
4. 宁可少跑，不可封号——账号价值 >> 自动化收益
